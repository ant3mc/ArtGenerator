# Art Generator

A real-time generative art application that creates dynamic, colorful, cloud-like  visual patterns using WebGL 2.0 with audio-reactive elements and many settings.

## 🌟 Features

- **Two Generation Methods**:
  - Simplex Perlin Noise( best ) with natural, organic patterns
  - Radial Gradient( economic) with smooth color transitions
  
- **Customizable Visuals**:
  - 8, 10, or 12 dynamic spots with breathing animations
  - Adjustable saturation, brightness, and opacity, Color variety
  - Three blend modes: Premultiplied, Straight Alpha, Additive
 ---
  - Auto-stop after 5 minutes

## 🎵 Audio Modes

The generator uses pentatonic scales for harmonious sound generation:

- **Base Frequencies**: A (440Hz) or C with standard (440Hz) or alternative (432Hz) tuning
- **Octave Ranges**:  2-octave or extended 3-octave ranges
- **Sound Mapping**: Each spot corresponds to a frequency based on its hue value( volume based on its brightness value)

### Browser Compatibility
- Requires WebGL 2.0 support
- Modern JavaScript (ES6+)
- Web Audio API for sound generation
- Fullscreen API for immersive experience

### Building and Customization
The application is contained in a single HTML file for easy distribution.
